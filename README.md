# workspace.smait.co.za

SMAIT Digital proposes the design and development of a secure, web-based Project Management Software that enables seamless collaboration between SMAIT’s internal teams (Admin) and their clients. The platform will centralise project tracking, communication, documentation, and progress reporting in one controlled environment.

The system will be role-based, with separate Admin and Client login portals, ensuring transparency, accountability, and real-time project visibility.

2. Objectives of the Platform

The primary objectives of the platform are to:

Improve project transparency for clients

Centralise all project communication and documentation

Allow SMAIT admins to manage multiple client projects efficiently

Reduce reliance on email, WhatsApp, and manual reporting

Provide clients with real-time visibility into project progress

3. User Roles & Access Control
3.1 Admin (SMAIT Digital Team)

Admins will have full control over the system and all projects.

Admin capabilities include:

Create and manage client accounts

Assign login credentials (username & password) to clients

Create, update, and manage multiple projects

Update project statuses, milestones, timelines, and deliverables

Upload project files, reports, and assets

View and respond to client messages in real-time

Monitor overall project progress across all clients

All updates made by the Admin will automatically reflect on the client’s dashboard in real time.

3.2 Client Portal

Clients will have secure access to their own projects only.

Client capabilities include:

Log in using credentials created by the Admin

View project overview, status, and progress timelines

Track milestones and percentage completion

Upload project briefs, documents, and supporting files

Engage in direct chat with the SMAIT Admin team

View all updates, comments, and uploaded assets in one place

Clients will not be able to modify project structure or admin-level data, ensuring system integrity.

4. Core Features & Functionality
4.1 Project Dashboard

Project name, description, and assigned team

Current status (e.g. Pending, In Progress, Review, Completed)

Progress indicators (percentage or milestone-based)

Last update timestamp

4.2 Project Updates & Progress Tracking

Admin updates automatically reflected on client view

Milestone tracking with dates and notes

Activity log showing all updates and interactions

4.3 Document & Brief Uploads

Secure file upload system for clients and admins

Support for briefs, PDFs, images, videos, and documents

Files linked directly to specific projects

4.4 Internal Chat & Communication

Built-in real-time chat between client and admin

Conversation history saved per project

Reduces fragmented communication across platforms

4.5 User Account Management

Admin-created client accounts

Password-protected logins

Ability for admin to reset passwords or deactivate accounts

5. Security & Data Protection

Role-based access control (Admin vs Client)

Secure authentication and encrypted passwords

Clients can only access their own projects and data

Secure file storage and access permissions

6. Scalability & Future Enhancements (Optional)

The platform will be designed to allow future expansion, including:

Notifications & email alerts

Task assignments and deadlines

Automated reports

Billing and invoice tracking

AI-assisted project summaries

7. Conclusion

This Project Management Software will position SMAIT Digital as a structured, transparent, and tech-forward agency, improving client trust while increasing internal efficiency. By centralising projects, communication, and documentation, SMAIT will reduce operational friction and elevate the client experience.
